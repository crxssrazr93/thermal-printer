UI/UX design directions

Five visual directions for the thermal printer app. Static mockups only, nothing is wired up. Each has a light/dark toggle in its own header. Same screen in every one, so they can be compared like for like.

01

Swiss Console

Hairline 12-column grid, monochrome with one blue accent, dense and quiet. Closest to a professional instrument.
